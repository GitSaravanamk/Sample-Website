Pipeline

  1. Code is pushed to GitHub
  2. GitHub Actions builds the Docker image
  3. The image is pushed to Docker Hub
  4. Docker runs the image and serves this page

About

This page is served from a container. Visitors receive only the built website, not the repository or its history.
